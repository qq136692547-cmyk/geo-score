定价常见问题

GeoScore 真的免费吗？

单次浏览器审计、CLI 和 MCP Server 免费。登录可选；Pro 监控和历史记录为付费功能。源代码以 MIT 协议开源在 GitHub。

需要信用卡吗？

Free 计划无需信用卡。Pro 计划包含 7 天免费试用，试用期结束后才会扣费。

可以随时取消吗？

可以。在客户门户随时取消，当前计费周期结束前保持访问权限。

GeoScore 和 GeoReady 有什么不同？

GeoScore 是开源的（MIT），支持中文，内置 CLI 和 MCP Server；免费浏览器审计包含提示注入检测。GeoReady 对类似监控功能收费 $9-89/月。

你们处理 VAT 和税务吗？

是的。我们的支付合作伙伴 Creem 作为记录商户（MoR），自动处理 190+ 个国家的 VAT、GST 和销售税合规。您无需操心税务表格。

Studio 和 Agency 什么时候推出？

Studio 和 Agency 即将推出。我们先以 Pro 启动，验证工作流程。请关注我们的 GitHub 仓库 获取更新。
