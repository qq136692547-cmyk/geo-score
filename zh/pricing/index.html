定价常见问题

GeoScore 真的免费吗？

单次浏览器审计、CLI 和 MCP Server 免费。登录可选；Pro 监控和历史记录为付费功能。源代码以 MIT 协议开源在 GitHub。

需要信用卡吗？

Free 计划无需信用卡。Pro、Studio 和 Agency 计划均包含 7 天免费试用，试用期结束后才会扣费；Pro 年付按年一次性支付 $79，不提供试用。

可以随时取消吗？

可以。在客户门户随时取消，当前计费周期结束前保持访问权限。

GeoScore 和闭源的 GEO 监测工具有什么不同？

GeoScore 是开源的（MIT）：提供 CLI 和 MCP Server，可指向任意 LLM 端点；免费浏览器审计还包含提示词注入检测。闭源监测套件按域名收月费，评分逻辑不公开。它们报告 AI 引擎如何提及你；GeoScore 审计的是你的站点为这些引擎提供了哪些可用素材——11 个维度，并附可直接应用的修复文件。

你们处理 VAT 和税务吗？

是的。我们的支付合作伙伴 Creem 作为记录商户（MoR），自动处理 190+ 个国家的 VAT、GST 和销售税合规。您无需操心税务表格。
