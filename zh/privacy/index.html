隐私政策

最后更新：2026-07-21

1. 概述

GeoScore 是一个开源 GEO 审计工具，提供免费单次浏览器审计和可选 Pro 监控。本政策解释不同模式分别收集哪些数据以及原因。

2. 我们不收集的数据

GeoScore 审计 100% 在客户端运行。当你输入 URL 进行审计时：

  • URL 直接从你的浏览器获取到公共代理和目标站点。
  • 单次浏览器审计不会把 URL 发送给 GeoScore 存储；浏览器会直接或通过 CORS 代理请求公开资源。
  • URL 绝不会被记录、绝不会被存储，也绝不会被分享给第三方。

3. 我们收集的数据

我们使用 Google Analytics 4 (GA4) 了解聚合流量模式。GA4 收集：

  • 页面浏览（仅 URL 路径，不含审计 URL 的查询字符串）
  • 来源（你来自的上一个网站）
  • 国家和城市（从 IP 推导，然后丢弃）
  • 设备类型、浏览器、操作系统
  • 屏幕分辨率和视口大小

已启用 IP 匿名化。我们未启用 Google Signals。我们不使用广告 Cookie。

4. Cookie

GeoScore 不使用第一方 Cookie。GA4 可能设置自己的 Cookie 用于访客识别；你可以通过浏览器的 Do Not Track 设置、Google Analytics 退测浏览器插件，或在浏览器中阻止第三方 Cookie 来退出。

5. 第三方服务

GeoScore 依赖以下第三方服务，各有其自己的隐私政策：

  • GitHub Pages（托管）— GitHub 隐私声明
  • Cloudflare Pages（CORS 代理）— Cloudflare 隐私政策
  • Google Analytics 4（分析）— Google 隐私政策

6. 儿童隐私

GeoScore 不面向 13 岁以下的儿童。我们不会有意收集儿童信息。如果你认为有儿童提供了信息，请联系我们以便删除。

7. 政策变更

我们可能不定期更新本政策。变更将发布在此页面并更新"最后更新"日期。重大变更将在 GitHub 仓库更新日志中注明。
