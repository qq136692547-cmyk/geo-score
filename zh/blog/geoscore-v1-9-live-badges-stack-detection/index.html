1. 实时动态 GEO 评分 SVG 徽章（10 秒嵌入 README / 官网页脚）

现在任何公开域名都拥有专属的动态评分徽章地址：https://geoscore.help/badge/你的域名。该端点运行在 Cloudflare Pages 边缘函数上，内置 SSRF 与内网 IP 过滤、手动跳转校验、350 KB 流式读取上限与 6 小时边缘缓存，并严格对齐引擎的四档评分配色（86+ 绿、68+ 蓝、36+ 琥珀、36 以下红）。

由边缘节点实时渲染的在线徽章示例：

Markdown 代码（适用于 GitHub README / 技术文档）

[![GEO Score](https://geoscore.help/badge/example.com)](https://geoscore.help/?url=https://example.com)

HTML 代码（适用于企业官网页脚 / 状态页）

<a href="https://geoscore.help/?url=https://example.com" target="_blank" rel="noopener">
  <img src="https://geoscore.help/badge/example.com" alt="GEO Score" />
</a>

安装 Chrome 扩展 v1.9.0 后，每次在侧边栏跑完审计都会自动展示当前网站的实时徽章预览，点击按钮即可一键复制 Markdown 或 HTML 嵌入代码。

常见问题

GeoScore 实时 SVG 评分徽章如何嵌入网站或 GitHub README？

只需将图片地址指向 https://geoscore.help/badge/你的域名 即可。Cloudflare 边缘节点会自动完成公开站点评分并缓存 6 小时，按分数段展示四档颜色，Chrome 扩展 v1.9.0 侧边栏也支持一键复制 Markdown 与 HTML 嵌入代码。

Chrome 扩展 v1.9.0 支持自动识别哪些建站技术栈？

扩展内置的 stackDetector.js 可在本地零外传自动识别 Shopify、WordPress 与 Next.js，并在侧边栏与网页修复文件面板中直接给出对应平台的部署步骤。

腾讯 WorkBuddy「国内企业官网 GEO 引文优化专家团」和网页版有什么区别？

WorkBuddy 专家团面向需要优化 Kimi、豆包、DeepSeek、秘塔和元宝等国产大模型引文的国内企业官网，采用 ¥29 一次性买断制（国内便捷支付），纯本地零依赖运行 9 大国产 AI 爬虫诊断、ICP/公安备案信任核验、中文修复包生成与离线 SVG+HTML 战报；如需 48 小时人工代写并复检上线，也可选择 Fix Pack ($49)。
