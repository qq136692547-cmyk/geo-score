使用条款

最后更新：2026-07-21

1. 接受条款

使用 GeoScore 即表示你同意这些条款。如果你不同意，请不要使用本工具。

2. 服务描述

GeoScore 是一个免费审计工具，从 12 个维度对网站的 AI 搜索可见性（生成式引擎优化）进行 0-100 评分。该工具完全在你的浏览器中运行；我们不运营任何应用服务器。

3. 可接受的使用

你同意不会：

  • 使用 GeoScore 高频审计你不拥有或未获得明确许可的网站（速率限制：每个 IP 每 5 秒 1 次审计）
  • 尝试反编译、反逆向工程或以其他方式提取源代码用于商业转售（源代码已采用 MIT 许可证并在 GitHub 上公开）
  • 使用自动化脚本抓取审计结果用于商业目的而未获许可
  • 干扰服务、代理服务器或我们依赖的任何第三方服务的运行

4. 审计结果免责声明

GeoScore 提供基于公开可观察信号的尽力而为的启发式评分。该评分仅供教育和方向性参考；不保证在任何 AI 搜索引擎中的排名或引用。AI 搜索算法频繁变化，工具可能不反映最新信号。

不保证任何具体结果（爬取、索引、排名、引用）。将工具的建议作为起点，而非确定真理。

本服务按"原样"和"按可用状态"提供，不附带任何明示或暗示的保证，包括但不限于适销性、特定用途适用性和不侵权的保证。我们不保证服务将不间断、安全或无错误。
