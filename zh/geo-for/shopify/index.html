1. 通过 Content > Files + URL 重定向发布 llms.txt

Shopify 不支持直接向网站根目录上传静态文本文件。最稳妥的原生做法是将文件上传至 Shopify CDN，再将 /llms.txt 重定向过去：

  1. 编写简洁的 llms.txt，概括店铺主营品类、畅销系列、物流退换货政策与核心页面链接。
  2. 在 Shopify 后台打开 Content > Files，上传 llms.txt 并复制生成的 CDN 文件 URL。
  3. 前往 Online Store > Navigation > View URL redirects（或 Content > Menus > URL Redirects），新建一条从 /llms.txt 到该 CDN 地址的重定向。
# Your Store Name

> 店铺主营商品、配送范围与质保政策简介。

## Key Collections
- [Best Sellers](https://yourstore.com/collections/best-sellers): 畅销商品合集
- [Shipping & Returns](https://yourstore.com/pages/shipping): 配送与退换政策

2. 在 templates/robots.txt.liquid 中配置 AI 爬虫

Shopify 支持通过 templates/robots.txt.liquid 自定义爬虫规则。请务必保留 {{ robots.default_groups }} 以维持结账与后台路径保护，随后显式放行主流 AI 搜索爬虫： 

{% for group in robots.default_groups %}
  {{- group.user_agent -}}
  {% for rule in group.rules %}
    {{- rule -}}
  {% endfor %}
  {%- if group.sitemap != blank -%}
    {{ group.sitemap }}
  {%- endif -%}
{% endfor %}

3. 在商品模板中校验 Product JSON-LD

确保 Product 结构化数据仅在商品页输出（使用 {% if template contains 'product' %} 或置于 sections/main-product.liquid），并完整提供价格、币种、库存状态及 sku/gtin/mpn 标识符： 

{% if template contains 'product' %}
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": {{ product.title | json }},
  "description": {{ product.description | strip_html | truncate: 300 | json }},
  "sku": {{ product.selected_or_first_available_variant.sku | json }},
  "brand": { "@type": "Brand", "name": {{ product.vendor | json }} },
  "offers": {
    "@type": "Offer",
    "priceCurrency": {{ cart.currency.iso_code | json }},
    "price": {{ product.selected_or_first_available_variant.price | money_without_currency | json }},
    "availability": "https://schema.org/{% if product.available %}InStock{% else %}OutOfStock{% endif %}",
    "url": {{ shop.url | append: product.url | json }}
  }
}
</script>
{% endif %}

Shopify GEO 常见问题

如何在 Shopify 店铺中添加 llms.txt？

在 Shopify 后台进入 Content > Files 上传你的 llms.txt 文件并复制生成的 CDN 链接，然后进入 Online Store > Navigation > View URL redirects（或 Content > Menus > URL Redirects），创建一条从 /llms.txt 指向该 CDN 文件地址的 URL 重定向，即可在根域名路径下稳定访问。

如何在 Shopify 的 robots.txt 中放行 GPTBot 和 ClaudeBot？

进入 Shopify 后台 Online Store > Themes > Edit code > Templates > Add a new template，选择 robots.txt 创建 templates/robots.txt.liquid。保留 {{ robots.default_groups }} 默认规则，在末尾为 GPTBot、OAI-SearchBot、ClaudeBot、PerplexityBot 和 Google-Extended 添加 Allow: / 规则。

Shopify 主题中 Product JSON-LD 应该放在哪里？

应当将 Product JSON-LD 放在商品模板或 main-product 区块中，并通过 template contains 'product' 条件包裹，切勿挂在首页。需完整输出每个变体的价格、币种、库存状态以及 sku、gtin 或 mpn 等商品标识符。

Shopify 自带基础 SEO 标签，为什么还需要做 GEO 审计？

许多 Shopify 默认主题或第三方插件会遗漏变体级标识符（sku、gtin、mpn），或输出不包含店铺真实商品目录信息的通用接口，甚至产生结构化数据冲突。实时审计可以验证 AI 爬虫实际解析到的内容。
