1. Live Dynamic GEO Score SVG Badges (Embed in 10 Seconds)

Every public domain now has a live, cache-backed SVG badge at https://geoscore.help/badge/<domain>. Powered by a Cloudflare Pages edge function with SSRF/private-IP filtering, manual redirect verification, a 350 KB streaming read cap, and a 6-hour edge cache, the badge automatically reflects your latest 0–100 score and color tier (86+ green, 68+ blue, 36+ amber, <36 red).

3. Accurate 6-Endpoint Background Scoring & 3-Mode Web Audits

Full 6-Endpoint Silent Background Audit (Extension v1.9.0)

Previously, silent toolbar badge checks only sampled a subset of discovery files, which could under-report scores compared to opening the Side Panel. In v1.9.0, the MV3 service worker checks all six non-HTML discovery endpoints—robots.txt, llms.txt, sitemap.xml, /ai/summary.json, /ai/faq.json, and /.well-known/ai-plugin.json—so your toolbar badge score matches the full Side Panel report.

Unified 3-Tab Hero Switcher on geoscore.help

On the web app, you can now switch cleanly between Single URL, Batch Sitemap, and Compare Sites directly inside the hero audit panel—making competitor benchmarking and multi-page audits much faster.

Frequently Asked Questions

How do GeoScore live SVG badges work?

Point any Markdown or HTML image tag at https://geoscore.help/badge/yourdomain.com. A Cloudflare Pages edge function audits your public site, caches the SVG badge for 6 hours, and color-codes your 0–100 score across four tiers (86+ emerald, 68+ blue, 36+ amber, under 36 red).

Which tech stacks does GeoScore Chrome Extension v1.9.0 detect automatically?

GeoScore Chrome Extension v1.9.0 automatically detects Shopify, WordPress, and Next.js locally inside your browser and displays stack-specific deployment steps directly inside the Side Panel.

Does the live badge endpoint expose private or internal IP addresses?

No. The /badge/[domain] edge function enforces strict domain validation, SSRF and private-IP blocking, manual redirect checks, and a 350 KB streaming read cap so only public production domains are scored.

How accurate is the background tab score badge in Chrome Extension v1.9.0?

Version 1.9.0 upgrades the background service worker to inspect all six non-HTML discovery endpoints (robots.txt, llms.txt, sitemap.xml, /ai/summary.json, /ai/faq.json, and /.well-known/ai-plugin.json) so toolbar scores match full Side Panel audits.
