## 一、功能差在哪：差在"证据层"，不在"检查项数量"

| | 他们 | 我们 |
|---|---|---|
| 分数从哪来 | **真去问模型**，按 prompt × 引擎 × 天跑，存原始回答 | 静态抓 HTML 跑规则 |
| 「AI 可见度」 | 真实响应 | 官网自标 **"simulated … not real engine traffic"** |
| 爬虫 | **日志级**（Rankscale $99 档接 Cloudflare 只读，看 live fetch / search crawl / training crawl） | 只有"robots 允不允许"（意图，不是事实） |
| 引用来源 | 谁在 AI 回答里被引用 | 无 |
| 计量单位 | prompt / credit / check | 域名 |

**结论：不是 85 项比 200 项少，是"问卷"与"体检"的差别。**
买家（代理商、被 AI 抢流量的站）要的是"AI 昨天怎么描述我"，不是"我的 HTML 准备好了吗"。

**我们真有的（按可辩护程度排序）**
1. **一次生成三份可部署文件**（llms.txt + robots.txt + JSON-LD）——但 Geol.ai 的 **$9 档**也给三份，所以它值 $9，不值更多
2. **免登录、免邮箱、URL 不上传**
3. **提示词注入检测 + 负面信号**——11 家产品页**没有一家提到**。但"没人做"也可能是"没人要"，不能当护城河
4. 开源 + 中文

## 二、GEO 和 SEO 差在哪：官方答案是"还不构成独立品类"

- Google 官方（2026-07-10）："optimizing for generative AI search is optimizing for the search experience,
  **and thus still SEO**"；机制是 RAG + query fan-out，建立在核心排名系统上。
- 它专门辟了 "mythbusting" 一节：**llms.txt 这类机器可读文件不是必需的**；且明确说该文件
  "neither harm nor help"，Search 直接忽略。
- Ahrefs 137,210 域名日志实测（2026-06）：**97% 的 llms.txt 在 2026 年 5 月零请求**，
  有请求的里面只有 19.5% 来自具名 AI 工具；**0 个 bot 会去找不存在的 llms.txt**。
- 学术侧（KDD'24）：GEO 确实能提可见度，**最多 40%**，但靠的是**内容改写**，且效果因领域而异。
  它支持的是 contentQuality，不支持任何"配置类"指标。

**对我们 11 维的判决**：22/98 分（aiGuidance 12 + discovery 6 + agent 4）押在没有证据或已被否定的维度上；
权重最高的 14 分（structuredData）没有一手证据；真正站得住的只有 contentQuality + eeat = 20 分。

## 三、定价差在哪：不是价格，是计价单位

- 全行业按**提问量 / 响应量**加价（prompt / credit / check），域名与席位基本不限量。
  只有我们按**域名**分层。→ 5 域名 + 不限次审计，对 $9 用户永远够用 → **没有升级阈值 → NDR 结构性为 0**。
- 实价：**$0.016–0.082 / 次响应，中位约 $0.02**（分母统一后）。
- **中文竞品也按"词条数"收费，且价格远高于我们的推断**：
  豆智 DZOS 官网（aigcgeo.com，2026-10-23 主理人直读）价目为
  **10 词条 9800 元/季起、20 词条 18000 元/季、30 词条 26000 元/季**（按季支付、按月考核效果），
  折合 **约 3267 元/月起**（≈ $470/月）。
  ⚠️ 更正：行业文章流传的"5000 元/月起"是**二手口径**，官网一手数据是**按季计价**，
  月均折算低约 1/3，但**仍然是我们的 60–80 倍**。
  ⇒ "按提问量计费"在中英文市场同时成立，只有我们按域名。
  ⇒ 中文市场形态确认：**销售驱动、按词条打包、含人工服务**，没有自助注册入口、没有公开 API 文档。
- **真实追踪的入门锚 = $29**，两个互不相干的团队同时落在这个价（Otterly Lite / elmo Cloud）。
- **$9 档存在，但不含监测**（Geol.ai Starter $9：5 次扫描 + 5 次格式生成，FAQ 明写不含 AI monitoring）。
  所以我们 $9 卖"历史 + PDF + 模拟可见度"时，是在用一个不能卖的东西占着"AI 可见度"这个名字。
- 成本侧修正：elmo README 公开的 $0.15–0.35/1000 次只是**判定层**（Jev），抓取层无公开数字。
  ⇒ $29 是**价格锚**，不是成本地板。$9 做真查在成本上成立，只是没人愿意拉低行业锚点。

## 四、三条战略调整（按可执行性排序）

### 调整 1｜把"AI 可见度"从付费权益里拿掉，或换成真查（二选一，不能拖）

现在的状态最坏：**既不能卖钱（是估算），又占着名字（用户以为买了监测）**。

- 方案 1a（保守）：Pro 权益改为"云历史 + PDF + 每周审计 + 三份文件"，删掉"AI 可见度"这一行
- 方案 1b（推荐）：**加真查层，$19/月 = 约 860 次响应**（4 引擎 × 5 prompts × 每周 ≈ 860）
  单响应 $0.022，落在零售带内、贴着 Otterly $0.016 与 Semrush $0.033
- 判据：上线后 30 天内，$19 档点击占定价页 CTA 的比例 ≥30%（**但见第五节：分母不够**）

### 调整 2｜计价单位从"域名"改成"提问量"

- 免费层：3 个域名、每次审计不限、**0 个监测 prompt**
- $9：审计 + 文件生成，**不含监测**（对齐 Geol.ai Starter）
- $19：**10 个监测 prompt × 4 引擎 × 每周**（约 170 次/月）
- $49：50 prompts + 竞品对标 + 爬虫日志
- 判据：第 2 个域名的添加率（现在无从谈起，因为我们根本没记过这个数）

### 调整 3｜定位收缩成"审计 + 修复文件"，把监测让给真正的监测商

理由：我们的 85 项检查在"技术可读性"这层是有价值的，但在"AI 怎么描述你"这层没有产品。
与其做半个体检，不如做一个**明确的、便宜的、一次性交付的工具**——这也正好对上 11 维里仅存的可辩护项
（contentQuality / eeat / 技术可读性）。

- 判据：把首页从"AI visibility audit"改成"AI readiness audit + fix files"，看 30 天内
  定价页跳出率与 CTA 点击是否变化（同样受分母限制）

## 五、一个绕不过去的前提

90 天 **2 次点击**、真人 14 pv / 11 天。
**上面所有"点击占比 ≥30%""第 2 域名添加率"的判据，在 30 天内都测不出来**——分母是两位数。

所以真实的选择只有两个：
1. **主动制造分母**：发 10 条消息 / 投 5 个目录，把定价页访问搞到 ≥200 次（需要人出面）
2. **不做定价实验**，只做不依赖流量的部分：调整 1 的 1a（删掉模拟可见度）+ 调整 2 的价目表结构调整

**我建议先做 2 里不依赖流量的那部分**，因为它是"改了就对"的；定价实验要么等人，要么等 11-05 的搜索数据。

## 六、这份结论的不确定性

- **Google ≠ 全部引擎**。ChatGPT/Perplexity 的检索与排序不公开，B/C 的证据主要来自 Google 与学术环境。
- **"无证据"≠"无效"**。structuredData 可能只是没人做过对照实验，我判的是"不能拿来卖"，不是"错"。
- **列表价 ≠ 成交价**。所有价格是公开标价；企业合同价不可得。
- **我们自己的 API 成本没实测**。$19 档的毛利是倒推，不是实测。
